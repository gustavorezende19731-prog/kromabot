# Kromabot

quero um app de traqueamento pessoal meu, vou poder me organizar com faturamento, lucro, quero que a primeira seção seja um dashboard. cujo nome do app vai ser Kroma, Aplique um efeito de vidro fosco (estilo Glassmorphism do iPhone) neste elemento [botões e seções]. Use um fundo semi-transparente branco com opacidade baixa, o efeito 'backdrop-blur' para desfoque do fundo, uma borda fina sutil semi-transparente para dar o efeito de reflexo de luz na quina, e uma sombra suave para dar profundidade. Garanta que o texto por cima continue com alto contraste e legível."
